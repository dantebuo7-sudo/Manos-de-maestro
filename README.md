# Manos de Maestro

Web de Manos de Maestro: remodelaciones y construcción en la Región de Los Ríos, Chile.
Miguel Saldivia e Ignacio Mora · WhatsApp +56 9 7710 7052

## Estructura
- `index.html`: la página completa (HTML, CSS y JS en un solo archivo).
- `img/`: fotos de las obras y el logo (formato WebP).
- `video/`: timelapse de empaste.

## Fotos
| Archivo | Qué foto es |

| `img/hero.webp` | Portada (cocina) |
| `img/story-1..3.webp` | Escalera: antes, proceso, terminado |
| `img/bano-1..3.webp` | Baño de mármol negro |
